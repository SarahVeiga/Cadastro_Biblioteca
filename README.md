# Cadastro Biblioteca

Este é um projeto simples de uma página web que lista livros, seus autores e seus anos de publicação. Para o seu desenvolvimento foi utilizado o MVC (Model-View-Controller), separando as responsabilidades entre os dados.

### - Funcionalidades

Exibe uma lista de livros com o nome, autor e ano de publicação.

Permite a adição de novos livros.

Organiza os dados utilizando o padrão MVC.

### - Estrutura do Projeto

- Model:
  
O Model é responsável pela representação dos dados. No caso do nosso projeto, ele gerencia os livros, com informações como nome, autor e ano de publicação.

- View:
  
A View é responsável pela apresentação dos dados ao usuário. Ela exibe a lista de livros e fornece a interface para inserir novos livros.

- Controller:
  
O Controller é responsável pela lógica de controle da aplicação, coordenando a interação entre o Model e a View. Ele recebe os comandos do usuário, manipula os dados no Model e atualiza a View.

- CSS:

Uma breve e simples coloração para o fundo da página.
